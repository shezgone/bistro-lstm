- **방법**: 병렬 문헌 조사 8차원(에이전트 9, 논문 ~50편, 상위권 arXiv 검증) + 완결성 비판 + 당일 실측(Chronos-2 32분기 백테스트)
- **전제**: 국면 게이트 사용 불가(실권자), 소표본(평가 32분기), 기각 이력 7종 재제안 금지, "딥러닝으로 성과" 요구

## 1. 결정적 논리 — "성과"의 재정의 (비판 에이전트 종합)

- **검정력 불가능성**: 32분기에서는 6.2% 개선(v3 0.718)도 DM p=0.088. 한 자릿수 % RMSE 개선은 **달성해도 유의성 입증이 불가능** → 점 RMSE는 이겨도 결론이 안 나는 축.
- **실권자 선호**: 게이트 기각 = "점 예측을 건드리는 것"에 대한 불신 → 수용성 최대 영역은 예측 불변 부가 레이어 (7/22 피벗과 정합).
- **빈 기준선 4축**: 현직 시스템은 점추정만 출력. ①분포(fan chart, CRPS·coverage) ②설명(뉴스분해+LLM 리포트) ③개정예측 ④주차별 조기정보 프로파일 — 사내 기준선이 0이므로 **DL이 세우는 첫 결과가 곧 성과**.
- **권고 프레임**: "점 예측(DFM+XGB)은 불변. 딥러닝은 캘리브레이션된 fan chart + 조기 주차 정보 우위 + 자동 설명을 추가한다. 점 정확도는 비열등성으로 방어" — 딥러닝 명분·게이트 회피·예측 불변 동시 충족.

## 2. 문헌 지형 요약 (차원별 판정, 검증 인용)

| 차원 | 판정 | 핵심 근거 |
|---|---|---|
| ① 신형 TSFM | **주력** | Chronos-2(arXiv 2510.15821, 공변량 zero-shot SOTA — 당일 실측 완료), TiRex-2(2607.01204), TimesFM 2.5 LoRA, **TimesFM-ICF**(ICML'25, gradient 없는 few-shot=FT 동급), Moirai 2.0(대조군) |
| ⑥ 소표본 특효 | **주력** | **MACROCAST**(2606.28670): 빈티지 일관 + "자기 DFM으로 합성 코퍼스 생성→9분 미세조정" 레시피, ~80% 계열에서 OOS 개선. 단 반대증거(2605.06032: 증강 평균 67% 유해) → 어닐링+실데이터 게이트 필수 |
| ⑤ 확률예측 축 | **주력** | 밀도 나우캐스트가 DFM을 이긴 실증(2405.15579), TabPFN 분위수 1줄, XGB quantile(계량측 정직 바), conformal 3종(EnbPI/ACI/NexCP), 당일 실측(커버리지 49%)이 필요성 입증 |
| ④ 텍스트·고빈도 | **주력** | **한은 뉴스심리지수 NSI**(BOK WP 2022-15, 트랜스포머, ECOS 공개 — 수집비용 0·수용성 최고), ECB ChatGPT-PMI(WP 3063, ~20% 이득), 이득은 분기 전반부 집중(우리 조기 주차와 정합). +비판 추가: **관세청 1~10일 수출**(무개정 진짜 실시간 하드 신호) |
| ② 혼합주기 NN | 조건부 | NCDENow 완전판(CIKM'24, 한국 GDP, 공식 코드) — 단 "DFM 단독만 이겨선 무의미" → 팩터 임베딩을 XGB 피처로 결합하는 설계 포함 시에만 |
| ⑦ retrieval | 보류 | LoCalPFN kNN-컨텍스트(NeurIPS'24)는 반나절 실험이나, **연속형 국면 조건화로 해석될 정치 리스크** — 수용 범위 확인 선행 |
| ③ 다국가 풀링 | **중단** | 코퍼스 교정 가설 미검증 + 개정치/빈티지 분포 갭 구조적 + MACROCAST 합성이 같은 병목을 무갭으로 해결 → 잉여 |
| ⑧ 중앙은행 실증 | 설계 원칙 | 실시간 조건 DL 승리의 공통 설계 = DFM 골격 유지 + DL 단일 채널 담당 / 합성·사전학습 전이 / 텍스트 추가. IMF WP 2025/252: 직접학습 ML 6개국 전패(우리 이력과 정합) |

누락 보완(비판): **TabPFN 2.5 드롭인 업그레이드**(HF Prior-Labs/tabpfn_2_5, 회귀 87% win rate — 반나절, 후속 실험 전부 상향), KalmanNet(프런티어, 후순위).
