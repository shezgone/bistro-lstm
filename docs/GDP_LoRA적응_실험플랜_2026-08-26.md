# LoRA 적응 실험 플랜 — BISTRO · Chronos-2 (2026-08-26)

## 0. 연구 질문과 논문 포지셔닝

**RQ: 경량 적응(LoRA)이 동결된 시계열 FM에게 "실시간 나우캐스팅 과제"(빈티지 정보 흡수)를 가르칠 수 있는가?**

- 지금까지의 발견이 이 질문의 완벽한 전제: zero-shot에서 흡수율이 체크포인트마다 다름
  (C2f -9.3% vs BISTRO -4.7% vs XGB -24.8%) → "적응으로 이 격차를 메울 수 있는가"가 자연스러운 다음 장
- 논문 구도: zero-shot(완료) → GDP head(한은 완료, 실패) → **LoRA 적응(본 실험)** — 3단 사다리의 마지막 칸이자 최초 실측
- 2 체크포인트(공변량 네이티브 C2 vs any-variate BISTRO) 대조가 "훈련 방식이 적응 가능성도 결정하는가"라는
  두 번째 질문을 공짜로 제공 — 어느 방향의 결과든 기여가 성립

## 1. 실험 매트릭스

| 체크포인트 | zero-shot | +GDP head (한은) | +LoRA (본 실험) |
|---|---|---|---|
| Chronos-2 (120M) | 0.808 / 흡수 -9.3% ✅완료 | — | **실험 A** |
| BISTRO (91M) | 0.871 / 흡수 -4.7% ✅완료 | 1.05 / 평탄 ✅한은 완료 | **실험 B** |

판정 지표 (우선순위 순):
1. **흡수율** (주차별 RMSE, 초반 6주 → 다음 6주 감소율; w=-19~-8 자체 예측 구간) — primary
2. 전체 RMSE (w=-19~-8) 및 조기 슬롯 자격(조기 구간 GBM 0.924 대등 여부)
3. 반등 6분기, 2025 준청정 홀드아웃 별도 보고

## 2. 학습 데이터 설계 — "빈티지 경로" 단위 (한은 제안 수용)

학습 표본 1개 = (과거 분기 q, 주간 빈티지 v):
- **컨텍스트**: DFM 스냅샷@v를 빈티지 월까지 자른 패널 (N_gdp + 공변량 10종) + 빠른신호 4종@v
- **관측 마스크 채널**: 각 월이 실제 관측인지 DFM 추정인지 (발표시차 규칙으로 근사 재구성) — 공표달력 정보의 v1 구현
- **라벨**: q의 분기말 월 flash (h = 빈티지 월→분기말 월 거리, 1~6개월)
- Chronos-2: `chronos.chronos2.preprocess` 헬퍼로 공변량 포함 포맷 구성 → `fit(finetune_mode="lora")`
- BISTRO: uni2ts 2.0 파인튜닝 경로 (없으면 peft로 attention q/k/v/o에 LoRA 주입 + 분포 NLL 루프)

핵심: 모델이 배우는 것은 한국 GDP의 동학이 아니라 **과제의 형식** — "오른쪽 끝이 들쭉날쭉한(ragged-edge)
패널과 관측 마스크가 주어졌을 때 분기말 값을 맞히는 법". 이 형식은 분기마다 반복되므로
라벨 수보다 학습 가능한 구조 신호가 많다 — 4연속 전패한 "동학 직접학습"과의 차별점.

## 3. 검증 프로토콜 (누출 차단)

- **Walk-forward 재적응**: 평가 시점 T마다 베이스 체크포인트에서 fresh LoRA (적응 누적 금지).
  학습 경로 = q ≤ T-2 (속보 발표 완료 분기만, release-safe)
- **평가창 = 2021Q1~2025Q4 (20분기)**: 빈티지 경로가 2018Q1부터만 존재 → 적응 데이터 최소 12분기 확보 시점부터 평가.
  2018~2020은 zero-shot 수치로 비교 유지
- **재적응 주기**: v1은 연 1회(2021·22·23·24·25 초, 5회) — 계산 현실성. 개선 확인 시 분기별로 조밀화
- **검증 분할은 분기 그룹 단위**: 같은 분기의 경로 19개는 라벨을 공유하는 유사복제 —
  행 단위 분할은 라벨 누출로 성적 착시를 만듦. 시간순 분기 블록으로 내부 검증·조기중단
- **사전 등록**: rank·lr·steps·마스크 설계를 본 실험 전 고정(내부 검증으로만 선택), 설정 1개로 전 구간 실행.
  seed 3개 반복으로 재현성 보고
- **2025 홀드아웃 분리 보고**: BISTRO 사전학습(~2024)과 겹치지 않는 준청정 구간. 2018~2024는
  한은 리포트와 동일하게 "회고적 진단" 수위

## 4. 과적합 리스크 평가 (정직 버전)

**위험 요인**
1. **유효 표본의 착시**: 경로 수는 수백이지만 라벨(분기 flash)은 12~28개. 19배는 유사복제 —
   이것이 이 실험 최대의 함정이며, 분기 그룹 검증으로만 방어 가능
2. **전례**: 학습형 개선책 4연속 전패 (가중치·적응가중·잔차·합성). 소표본에서 "데이터가 정하게 하라"는 계속 짐
3. **오염 상호작용**: 사전학습 지식(≤2024) + 적응이 결합하면 회고 구간 성적이 부풀 수 있음 → 2025 분리 보고 필수
4. **사후 선택**: rank/lr/steps/마스크 조합 탐색 자체가 새로운 선택편의 → 사전 등록으로 차단

**그럼에도 시도 가치가 있는 이유**
- 배우는 대상이 다름: 동학(라벨 수만큼만 신호)이 아니라 **과제 형식**(모든 경로가 신호) —
  LoRA rank 4~8(전체 파라미터의 0.1~0.5%)이면 용량도 형식 학습 수준으로 제한됨
- 한은 head 실험이 실패한 지점(출력층만 교체)과 zero-shot의 한계(과제 미학습) 사이의
  마지막 미탐색 지대 — 여기서 실패해도 "3단 사다리 전부 실측"으로 논문 완결

**성공 확률 소견**: BISTRO 흡수 회복 = 중간 (깨진 것이 명확해 고칠 여지 존재) /
C2f 전체 RMSE 개선 = 낮음 (이미 준수, 개선 여지 협소) / 논문 가치 = 결과 방향 무관 성립.
기대의 중심을 "점수"가 아니라 "흡수율 곡선의 변화"에 둘 것.

## 5. 킬 기준

- 내부 검증(분기 그룹)에서 zero-shot 흡수율·RMSE 동시 미달 → rank/steps 절반으로 1회 재시도 → 재미달 시 해당 트랙 중단
- 흡수율 개선 + 전체 RMSE 악화 → "형식은 배웠으나 지식 손상" 판정, LoRA 강도 축소 1회 재시도
- 모든 결과는 seed 3개 평균으로 판정 (단일 seed 신기록 금지)

## 6. 실행 단계

| 단계 | 내용 | 예상 |
|---|---|---|
| Step 0 | C2 `fit(lora)` 왕복 스모크(소량 경로 적응→저장→재로딩→예측) ✅fit API 확인 완료 / uni2ts 2.0 파인튜닝 경로 확인 | 0.5일 |
